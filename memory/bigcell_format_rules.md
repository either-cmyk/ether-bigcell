## 1. 컬럼 처리 = 시트 헤더 이름기준 매핑 (★현행, slice 방식 폐기)

BigCell 엑셀 컬럼은 수시로 추가/재배치됨(자체상품코드·운영상태·본사발주검토 등). **고정 slice/인덱스 금지.**
판매 Data 시트 헤더(F~AX, 45필드) 순서에 **이름기준으로 재배열**해서 doPost에 보냄.
- 동일 이름 N번째 매칭(이익금 중복 대응), 품절예상일↔쿠팡품절예상일 부분매칭
- 반품 옵션 행(옵션명에 "반품" 포함) 제외
- 검증: 판매수량(AE, idx25)이 전 행 채워지는지. 적게 채워지면 정렬 깨진 것
- ❌ 폐기: `row.slice(0,6).concat(row.slice(7))` 같은 자체상품코드 고정제거 방식

## 2. 판매 Data D열 날짜 + 클린인테크 정규화 (★중요 정정)

- doPost는 D열에 문자열 `YYYY. M. D`(점 뒤 띄어쓰기, 월/일 0 없음)로 기록.
- 그로스 날짜 헤더와 매칭하려면 D가 **날짜값**이어야 함.
- **클린인테크는 doPost가 D를 텍스트로 남김 → doPost 직후 `normalizeDColumn`(action, 해당 startRow) 호출로 D 텍스트→날짜값 변환 후 그로스 컬럼 삽입.**
- ⚠️ 과거 "텍스트가 정답·normalizeDColumn 금지" 메모는 **폐기**. 실제로는 클린인 정규화가 필수다.
- 이더/뉴트리정/마인플로/이든은 기존 흐름대로 그로스 삽입 시 매칭 정상.

## 3. 그로스 날짜 헤더 = MM/DD 날짜값 표준 (이더 스타일)

- 그로스 재고 DB row2 날짜 헤더는 **날짜값 + `mm/dd` 표시형식**(예: 06/14)이 표준.
- 이더/뉴트리정/마인플로는 이미 MM/DD. 클린인테크는 텍스트("2026. M. D")·MM/DD 혼합이었으나 2026-06-15 v8 `etherizeDates`로 전부 MM/DD 날짜값 통일(백업→최신열 freeze→헤더 변환). 이후 신규 컬럼은 인접 형식 상속으로 자동 MM/DD.
- 혼합 재발 시 `{sheetId, action:'etherizeDates'}` 1회 재실행.

## 4. 클린인테크 SKU(I열) 주의 (유지)

- 클린인 doPost는 SKU ID(I열)를 원본 그대로 둠. row[3]을 날짜로 덮어쓰면 SKU ID 파괴→매칭 실패. 이름기준 매핑 사용 시 자동 안전.
