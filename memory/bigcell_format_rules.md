## 1. 판매 Data D열 날짜 형식 (5개 사업자 공통)

**확정일**: 2026-04-22

**형식**: 텍스트 `YYYY. M. D`
- 각 점(`.`) 뒤에 **띄어쓰기 1칸**
- 월/일은 **앞자리 0 없음** (4월 → `4`, 10월 → `10`)
- 예: `2026. 4. 21`, `2026. 4. 22`, `2026. 10. 5`
- **날짜 값이 고정인 게 아니라 "형식"이 고정**. 매일 해당 날짜로 바뀜

**적용 범위**: 이더컴퍼니/뉴트리정/클린인테크/마인플로/이든코퍼레이션 5개 사업자 전체

### 검증 결과 (2026-04-22 기준)
- 이더컴퍼니 D열 텍스트 `2026. 4. 21` → 그로스 재고 DB ARRAYFORMULA 매칭 정상
- 클린인테크 D열에 이더와 동일 텍스트 붙여넣음 → 매칭 정상
- **Date 객체로 변환 불필요. 텍스트 그대로가 정답**
- **normalizeDColumn 같은 정규화 시도 금지** (이미 텍스트가 정답)

### doPost 날짜 포맷 생성

```javascript
var target = new Date(Date.now() - 86400000);  // KST 어제
var date = target.getFullYear() + '. ' + (target.getMonth()+1) + '. ' + target.getDate();
// 결과: "2026. 4. 23"
```

## 2. BigCell Excel 컬럼 구조 (2026-04-22 변경)

### 변경 내용
2026-04-22부터 BigCell 로켓그로스 매출분석 export에 `자체상품코드` 컬럼이 **row[6]**에 추가됨.

### 엑셀 컬럼 구조 (변경 후)

| col | 내용 | 시트 매핑 |
|-----|------|----------|
| 0 | 스토어명 | F |
| 1 | 노출상품ID | G |
| 2 | 상품명 | H |
| 3 | SKU ID | I |
| 4 | 옵션ID | J |
| 5 | 옵션명 | K |
| **6** | **자체상품코드** | **❌ 제거 필수** |
| 7 | 판매가 | L |
| 8 | 원가 | M |
| 9 | 수입단가 | N |
| 10 | 이익금 | O |
| 11 | 고객반품 | P |

### 조치

- 5개 사업자 시트에서 기존 자체상품코드 열 삭제 완료 (L=판매가로 통일)
- 스킬 필터 코드에 반드시 적용: `var stripped = row.slice(0, 6).concat(row.slice(7));`
- 시트와 Apps Script 매핑은 기존 그대로 유지 (이더컴퍼니 기준)

### 재투입 이력 (2026-04-21, 열 삭제 전 misalign 발생 → 재전송)
- 이더: 1279행 (수동 처리)
- 뉴트리정: 96행 (startRow=483)
- 마인플로: 268행 (startRow=4292)
- 클린인테크: 204행 (startRow=3250)
- 이든: 4/21 당시 컬럼 비어있어 정상 처리

## 3. 클린인테크 Apps Script 특이 처리

### 공통 row 구조 (모든 사업자 BigCell 엑셀)
- row[0]=스토어명
- row[1]=노출상품ID
- row[2]=상품명
- row[3]=SKU ID
- row[4]=옵션ID
- row[5]=옵션명
- row[7]=판매가

### 이더컴퍼니/뉴트리정/마인플로/이든코퍼레이션 Apps Script
- `row[3] = '2026. 4. 21'` 덮어써도 내부 로직이 D열(날짜)와 I열(SKU ID)을 분리해서 정상 처리
- 기존 방식 그대로 유지 가능

### 클린인테크 (2026-06-10부터 5사 공용 doPost URL AKfycbxZ6SCV... 사용, sheetId 지정)
- row[3]을 그대로 I열에 넣는 **단순 로직**
- row[3]을 덮어쓰면 I열 SKU ID가 날짜로 파괴됨
- 결과: AP열 ARRAYFORMULA 매칭 실패

### 클린인테크 대응

1. **row[3] 덮어쓰지 말 것** (원본 SKU ID 유지)
2. **D열 날짜는 별도로 채워야 함** (사용자 수동 입력 또는 Standalone API normalizeDColumn 호출)
3. 스킬 실행 시 사업자별 분기 처리 필요
4. **복구 순서 (문제 발생 시)**:
   - (1) 해당 행 빈 rows로 덮어쓰기 clear
   - (2) row[3] 덮어쓰기 없이 원본으로 doPost
   - (3) D열 수동 입력
   - (4) Standalone API 호출
